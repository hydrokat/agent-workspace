# t-001: Standardize Node.js 26 LTS across Docker Compose, CI workflows, and .nvmrc

## Description
Pin and align the Node.js runtime to **Node.js 26 Active LTS (`26.x`)** across all container, local version-manager, and GitHub Actions workflow configurations in `task-tracker-web`. Currently, `docker-compose.yml` uses unpinned floating `node:alpine` and `node:latest` tags, `.github/workflows/staging.yml` uses Node `"24"`, `.github/workflows/production.yml` still specifies EOL Node `'20'` on `actions/setup-node@v3`, and no `.nvmrc` exists. Pinning `node:26-alpine` / `node:26` first ensures all subsequent dependency installation, build, and Dockerized Jest test steps in `t-002`–`t-004` execute inside the target Node 26 runtime.

## Requirement Classification
- **Type**: Enhancement
- **Rationale**: Upgrades and pins existing container and CI runtime configurations to Node.js 26 Active LTS for reproducible local and CI builds without altering product behavior.
- **Regression Risk**: Low - Docker Compose service startup (`react-app`, `prod`, `npm`, `npx`, `frontend-web`) and GitHub Actions `setup-node` steps must continue booting and mounting `./app-src:/react-app` identically.
