# Task 604: Implement E2E Tests for Points Engine & Rewards Lifecycle

## Description
Write Playwright tests to verify the point engine calculations and the reward claiming flow in the Nexus application.

## Objectives
- [ ] Implement an E2E test verifying that points are awarded correctly to a team/user immediately after an Admin approves a task.
- [ ] Implement an E2E test for a user/team claiming a reward using their accumulated points.
- [ ] Implement an E2E test for an Admin reviewing and approving the claimed reward.
- [ ] Include visual validation (screenshot capture) for the points balance update, reward claim submission, and final reward approval.
- [ ] Verify edge cases (e.g., attempting to claim a reward without sufficient points).
