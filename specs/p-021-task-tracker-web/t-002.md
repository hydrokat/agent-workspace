# t-002: Fix prod container .env shadowing and add validated public site-URL resolver

## Description
Fix a critical container environment shadowing bug in `docker/prod-entrypoint.sh` and introduce a typed, security-hardened site-URL and redirect-path helper module (`app-src/lib/config/site-url.ts`).

Currently, `docker/prod-entrypoint.sh` unconditionally exports fallback placeholders (`NEXT_PUBLIC_SUPABASE_URL=http://localhost:54321` and `NEXT_PUBLIC_SUPABASE_ANON_KEY=...local-build-placeholder`) whenever those variables are not pre-injected into the container shell environment. In staging/production (`staging.yml`), environment secrets are written to `app-src/.env` on disk rather than passed via `docker-compose.yml` `environment:`. Because Next.js (`@next/env`) never overrides variables already present in `process.env`, the entrypoint's shell exports shadow `app-src/.env`, causing `next build` and Server Actions (`requestPasswordReset`, auth flows) inside `prod` to call `http://localhost:54321` instead of the staging/production Supabase project.

Additionally, create `app-src/lib/config/site-url.ts` (following `knowledgebase/guidelines/environment-and-config.md`) to provide `resolvePublicOrigin()` and `sanitizeNextPath()`, ensuring deterministic HTTPS origin resolution behind reverse proxies (`NEXT_PUBLIC_SITE_URL` / `SITE_URL` override, comma-split `x-forwarded-host` / `x-forwarded-proto`, browser `origin` header fallback, host-injection rejection) and open-redirect-safe `next` query-parameter handling.

## Requirement Classification
- **Type**: Bug Fix
- **Rationale**: Fixes `.env` variable shadowing inside the `prod` container that routes staging/prod Supabase calls to `localhost:54321`, and provides the validated site-URL/origin resolution layer needed to prevent broken `http://` or malformed proxy `redirectTo` URLs.
- **Regression Risk**: Medium - Must preserve clean-checkout `docker compose run --rm prod npm run build` when no `.env` file exists (`p-020` `t-005`) while allowing `app-src/.env` values to take precedence when present.
