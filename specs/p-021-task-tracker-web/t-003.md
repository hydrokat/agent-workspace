# t-003: Harden forgot-password email dispatch, reverse-proxy redirectTo URLs, and auth recovery callbacks

## Description
Fix Forgot Password email dispatch and post-email recovery redirects in staging and production environments across `app-src/lib/actions/auth.ts`, `app-src/lib/actions/admins.ts`, `app-src/app/auth/callback/route.ts`, and `app-src/app/auth/confirm/route.ts`.

Four concrete code defects currently break password recovery in staging/production:
1. **Unnormalized email input**: `/forgot-password` styles the email input with CSS `uppercase`, and `requestPasswordReset(email)` passes raw `email` without `.trim().toLowerCase()`, failing validation on whitespace and sending mixed-case strings.
2. **Broken `redirectTo` origin behind reverse proxies**: `requestPasswordReset()` (and `inviteAdmin()`) builds `origin` via raw `${proto}://${host}` where `proto` defaults to `'http'` when Nginx omits `X-Forwarded-Proto` and fails with an invalid URI when Cloudflare + Nginx send comma-separated `X-Forwarded-Proto: https, http` or `X-Forwarded-Host`. Supabase GoTrue rejects malformed or `http://` non-allowlisted `redirectTo` URLs during `/recover`, preventing email dispatch.
3. **Broken query concatenation in `/auth/confirm`**: `app/auth/confirm/route.ts` appends raw `&recovery=true` onto `next` (`${next}${recoveryParam}`), turning `/reset-password` into `/reset-password&recovery=true` (HTTP 404).
4. **Broken error redirect & single-flow limitation in `/auth/callback`**: On failure, `app/auth/callback/route.ts` redirects to `${origin}/auth/auth-code-error` using the internal container `request.url` origin (`http://0.0.0.0:3000` or `http://localhost:3000`) instead of the public HTTPS origin, and does not handle `token_hash` + `type=recovery` links if a Supabase template targets `/auth/callback`.

Wire `resolvePublicOrigin()` and `sanitizeNextPath()` (from `t-002`) across all four files, allowlist safe Supabase rate-limit error messages in `requestPasswordReset()`, add non-PII diagnostic breadcrumbs/tags for Sentry triage, and document required staging/prod Supabase Auth Redirect URLs and Custom SMTP configuration.
