# Implementation Plan: Phase 005 - Admin Team Management & Invitation

## Phase Objectives
Enable detailed management of teams and a secure personnel invitation workflow. Admins will be able to deep-dive into specific teams, search for existing users, and invite new members via email with secure, one-time-use autogenerated passwords. 

**Strict enforcement of the [Supabase Atomic Migrations Guideline](../../knowledgebase/guidelines/supabase-atomic-migrations-guideline.md) is required. Schema modifications must NEVER alter existing migration files.**

## Architecture
- **Schema Extension**: Add `must_reset_password` flag to `profiles` table via a **NEW, atomic migration** exclusively. Existing migrations must remain untouched.
- **Admin Privilege**: Use Supabase Service Role client for account creation and team assignment to bypass normal RLS constraints where appropriate for admin actions. Server actions relying on schema changes must sequence after the migration is deployed.
- **Security**: Autogenerated passwords are cryptographically secure; `must_reset_password` is enforced via Middleware and a dedicated reset route.
- **UI System**: Nexus (high-contrast, industrial, `rounded-none`).
