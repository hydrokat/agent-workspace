# Task 305: Admin Submission Review UI

## Objective
Create a dashboard for administrators to efficiently review pending task submissions.

## Agent Assignment
- **Primary Agent**: `frontend-dev`

## Requirements
- Create `/admin/submissions` page.
- List view of all `pending` submissions.
- Show: Member Name, Task Title, Proof Content, Submitted Date.
- "Approve" and "Reject" buttons for each entry.
- Rejection should trigger a small modal/popover to provide feedback.
- Success/Error toast notifications.

## Deliverables
- [ ] Admin Review dashboard page.
- [ ] Rejection feedback modal.
