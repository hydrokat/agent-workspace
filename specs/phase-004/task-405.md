# Task 405: Admin Reward & Claim Management

## Objective
Provide admins with tools to manage the reward catalog and process member claims.

## Agent Assignment
- **Primary Agent**: `frontend-dev`

## Requirements
- Page: `/admin/rewards`.
- **Reward Management**:
  - List all rewards.
  - Simple form to Add/Edit rewards (Name, Description, Point Cost, `is_active`).
- **Claim Management**:
  - List all `pending` reward claims.
  - "Approve" and "Reject" buttons.
  - Approving sets `status = 'approved'` and `approved_at`.

## Deliverables
- [ ] Admin Rewards management page.
- [ ] Claim approval interface.
