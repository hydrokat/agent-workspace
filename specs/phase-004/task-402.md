# Task 402: Member Points & Task Dashboard

## Objective
Design and build the main dashboard for members to track their contributions and rewards.

## Agent Assignment
- **Primary Agent**: `frontend-dev`

## Requirements
- Page: `/dashboard` (Member-specific).
- **Components**:
  - **Points Overview**: Large display of total points.
  - **Progress Bar**: Visual milestone tracker for reward tiers (20, 40, 70, 100).
  - **Recent Activity**: List of recent `point_transactions` (e.g., "Task X - 30 pts").
  - **My Tasks**: List of joined tasks and their current submission status.
- Use `shadcn/ui` and follow the `nexus-ui` aesthetic if applicable.
- Adhere to `knowledgebase/guidelines/ui-design-guideline.md`.

## Deliverables
- [ ] Responsive Dashboard page.
- [ ] Point milestone/progress component.
