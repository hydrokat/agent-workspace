# t-005: AI CLI adapters + launch / add-agent wizard

## Description
Build the adapters that turn a user's choices into the exact argv for each official AI CLI, and the Textual wizard that collects those choices at startup (and later from F2 "New agent").

Wizard flow per agent (the user can add several before launching):
1. **Which AI CLI?** `claude` / `agy` (only installed ones are enabled; others are shown greyed out with a reason)
2. **Role?** Planner (left column) / Implementer (right column)
3. **Model?** Asked every time, with no hard-coded defaults (user decision). `agy` models come from `agy models` (cached for the session). `claude` offers aliases plus a free-text full model ID.
4. **agy only:** "Run with `--dangerously-skip-permissions`?" Default No, with a one-line warning.
5. **claude:** always `--permission-mode auto` (shown read-only so the user knows).
6. Optional: working directory / worktree for implementers (default: workspace root).

## Implementation Notes
Changed files (`agent-workspace-package/tandem`): NEW `src/tandem/adapters/{__init__,base,claude,agy}.py`, `src/tandem/wizard/{__init__,flow,app,runner}.py`, tests `test_adapters.py`, `test_wizard_flow.py`, `test_wizard_app.py`, `test_wizard_runner.py`.

Decisions:
- Model ids are validated by `^[A-Za-z0-9][A-Za-z0-9._:\-]{0,99}$` (no leading `-`, so an id can never be read as a flag) and always passed as a separate argv element. Argv is a `list[str]`; no shell strings anywhere.
- Claude is always `--permission-mode auto` and rejects `skip_permissions`; `--dangerously-skip-permissions` exists only on agy and only when chosen (default No, with a "Warning:" prompt).
- Env added to AI panes is exactly `TANDEM_SESSION_ID/ROLE/CLI/COORD_DIR` (`session_env`); session id is `<role>-<n>`, claude `-n` name `tandem-<role>-<n>`.
- `agy models` (real output: `id<TAB>label` after a header line) is parsed with a strict line regex, 10 s timeout, injectable runner; failures raise `ModelListError` and the wizard falls back to typing an id.
- Claude model list is the constant `CLAUDE_ALIASES` (opus, sonnet, fable; taken from `claude --help`) plus free-text ids.
- Wizard = pure `WizardFlow` state machine (tested without UI) + one-screen Textual `WizardApp`; `single=True` reuses it for F2. Esc goes back one step; Esc at the first step cancels.
- Models load in a worker thread so the UI never blocks.
