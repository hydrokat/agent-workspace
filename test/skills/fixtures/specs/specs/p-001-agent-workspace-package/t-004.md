# t-004: Coordination-aware `spec-planner`, `spec-implement`, AGENTS.md, in-progress template

## Description
Update the shipped skills and base files so every agent uses the coordination protocol from t-003, following the user's role-based awareness rule:
- **Planners** check current and planned implementations (`coord.py overview`, open claims, `specs/` statuses, `in-progress.md`) before planning, so no plan conflicts with running or planned work. Every task they plan records **Affected Paths** so conflicts can be detected.
- **Implementers** claim before working, use a worktree/branch per task whenever another implementer is active, heartbeat while working, and release on completion.
- **Everyone** asks questions through `coord.py ask` and keeps working on anything outside the question's blocking scope. Nothing gates the whole implementation on an unanswered question.
- All of the above is visible to the user in tandem's status window (t-007/t-008).

## Requirement Classification
- **Type**: Enhancement
- **Rationale**: Extends existing skills and the AGENTS.md concurrent-awareness principle (§8) with machine-readable steps.
