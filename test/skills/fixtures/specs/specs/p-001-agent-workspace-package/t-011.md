# t-011: Save AI state: resume each agent's conversation and recover from crashes

## Description
tandem's save/resume (PR #7) restored only the agent lineup and layout, and saved only on a clean `F10` exit. Save **AI state** too (each agent's conversation ID) and autosave while running, so that after a crash or a graceful exit the user can resume the same agents *and* chats, or start fresh.

## Requirement Classification
- **Type**: Enhancement
- **Rationale**: Extends the existing `state.py` save/resume flow.
- **Regression Risk**: Medium. Touches launch argv for both CLIs, the F10 menu, F11 restart, and the state file format (v1 → v2, v1 still readable).
