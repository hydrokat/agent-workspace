# Lessons Learned

Log every non-trivial lesson discovered during development. Entries should be
actionable — the next contributor should be able to avoid the same pitfall.

## Template

```markdown
## YYYY-MM-DD: Short Title

**Category:** Performance | Security | Testing | Architecture | Operations

### What happened
Brief description of the issue or discovery.

### Root Cause
Why it happened.

### Fix / Resolution
What was done to resolve it.

### Prevention
What practice, check, or automation would prevent recurrence.
```
