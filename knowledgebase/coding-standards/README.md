# Coding Standards

Language-specific and framework-specific conventions that supplement the
cross-cutting guidelines.

## Contents

Each language or framework gets its own file:

- `typescript.md` — Module system, async patterns, type conventions
- `php.md` — PSR standards, strict types, naming
- `rust.md` — Ownership patterns, error handling, crate conventions
- `sql.md` — Query formatting, join conventions, CTE usage
- `css.md` — Tailwind, naming conventions, design tokens
