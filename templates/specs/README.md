# Specs

Use this directory for implementation plans, tasks, and execution breakdowns.

New phase directories should use `p-###-[name-of-repo]` for single-repository work, or `p-###-multi` when a phase spans multiple repositories. Task files inside a phase should use `t-###.md`. Each phase `impl.md` should list the repositories involved and the role each repository plays.

For frontend or user-interface features and enhancements, spec plans and affected task files should include low-fidelity UI mockups that show the primary screens or components, responsive variants, important states, interaction notes, and accessibility considerations before implementation starts.
