# Agents Catalog

This directory contains vendor-agnostic agent definitions for role-based delegation within the workspace.

## Conventions

- Each agent lives in its own directory.
- Each directory contains a single `AGENT.md` file with structured frontmatter and operating instructions.
- Agent definitions describe responsibilities, invocation guidance, expected outputs, and guardrails without assuming a specific model provider or orchestration platform.

## Available Agents

- `codebase_investigator`
- `generalist`
- `business-analyst`
- `code-reviewer`
- `frontend-dev`
- `qa-engineer`
- `security-auditor`
- `senior-backend-dev`
- `tech-lead-orchestrator`
- `technical-writer`
- `terminal-agent`
